# Codexy iPhone MVP 验收

## 目标

使用一台 Windows 电脑、同一 Tailnet 中的一台 iPhone 和至少两个并行 Codex CLI，
验证安装、通知、深链、回复速览、会话控制、远程 Prompt、草稿隔离和 Prompt 回放。

## 安装前检查

```powershell
npm.cmd run check
npm.cmd run private:build
npm.cmd run release:check
npm.cmd run diagnose
```

`diagnose` 必须能分别显示 Node、Codex、Tailscale、Relay 8797、App Server 4510、
全局 Hook 与 `codexy` 启动器状态。

## iPhone 安装

1. 在电脑预演 `npm.cmd run setup`。
2. 确认范围后运行 `npm.cmd run setup:apply`；需要开机启动时改用管理员 PowerShell
   执行 `.\scripts\setup-codexy.ps1 -Apply -InstallStartup`。
3. iPhone Safari 打开脚本给出的私有 `https://...ts.net:8443` 地址。
4. 选择“分享 → 添加到主屏幕”，从主屏幕打开 Codexy。
5. 连接 Relay，在电脑领取配对码，再回到设置页开启后台通知。

## 功能验收

1. 在两个项目目录分别运行 `codexy`，发送不同 Prompt。
2. 手机出现两条独立轨道，短码不同，最近 Prompt 不串线。
3. 在第三个终端触发等待用户决定；锁屏时收到横幅。
4. 点击横幅，必须直达对应会话。
5. 点“我知道了”后会话仍保持“需要你决定”；回电脑真正处理后才变化。
6. 为两个会话分别写草稿，来回关闭和打开，内容仍各自保留。
7. 打开一条已有完整回复的手机可控轨道；顶部必须先显示最新一轮回复速览，包含
   一句结论和 2–4 条结果、验证、注意事项或下一步。手动刷新后内容仍对应同一会话。
8. 回复速览下方的控制台默认只显示一行当前模型、思考强度和常用操作；点“调整”
   后才展开完整控制面板，点“收起”恢复一行。
9. 展开一条手机可控轨道的控制台；模型列表必须来自电脑，并显示当前模型、思考强度、
   权限配置和会话状态。
10. 选择另一个模型和思考强度；确认页必须写明当前回合不变、下一轮生效，确认后
   `/status` 刷新仍显示新配置。
11. 运行中的会话只能使用 STOP，空闲会话才能使用 `/compact` 与 `/review`；
   三项都必须先出现二次确认。
12. Queue 一条 Prompt，发送前页核对目标、模式和全文；在未送达时测试撤回。
13. 将通知语气切到“有点人味”，频率切到“只推需要我”，触发一次测试事件。
14. 停止 Relay，10 秒内应显示离线；草稿保留，控制和发送均被禁用。
15. 恢复 Relay 后发送草稿，回执必须明确送达状态。
16. 同一会话连续 Queue 两条 Prompt，必须严格按先后顺序送达；第一条运行时第二条
    保持等待。
17. 撤回一条 waiting Prompt，电脑不得收到空 Prompt 或迟到指令；草稿仍保留。
18. 在设置中撤销设备，Relay 状态应删除该设备，浏览器 Push Subscription 与本机
    草稿一并清理。
19. 重新配对另一台手机后，旧手机不再收到新的 Hook 事件，新手机正常接管。

## 通过标准

- 无 Prompt、路径、代码或工具内容出现在系统横幅。
- 同一会话通知延续更新，不同会话不会跳错。
- `turn_finished` 始终描述为“本轮结束”。
- 手机不显示原始 thread ID、工作目录或模型缓存路径。
- 回复速览不显示完整回复、代码、绝对路径、链接、邮箱或疑似密钥，且不进入系统横幅。
- 快捷控制走原生 App Server 操作，不作为用户 Prompt 写入最近十条。
- 断线与失败不出现假成功。
- Prompt 只有在电脑确认送达后才清除手机草稿。
- 每条 Prompt 独立执行 24 小时保留上限，活跃会话也不能延长旧 Prompt。
- 普通用户日常只需在项目目录运行 `codexy`。
